A high-performance, mobile-first, interactive TNPSC Exam Preparation Web Application featuring **115 comprehensive, segment-based questions** derived strictly from the official 96-page study material (`UNIT - 6 [ TN HISTORY ]`).

---

## 🌟 Key Features

- **🏛️ 115 High-Yield Questions**: Meticulously crafted across 6 key segments following TNPSC Group 1, Group 2, and Group 4 exam standards:
  1. **தமிழ் சமூக வரலாறு & சங்க காலம், தொல்லியல் சான்றுகள்** (25 வினாக்கள்)
  2. **பாளையக்காரர்கள் புரட்சி & 1806 வேலூர் புரட்சி** (20 வினாக்கள்)
  3. **விடுதலைப் போராட்டத்தில் தமிழகத்தின் பங்கு** (20 வினாக்கள்)
  4. **நீதிக்கட்சி & சுயமரியாதை இயக்கம்** (20 வினாக்கள்)
  5. **தமிழக அரசியல் தலைவர்கள் & நலத்திட்டங்கள்** (15 வினாக்கள்)
  6. **திருக்குறள் & அற இலக்கியங்கள்** (15 வினாக்கள்)

- **⚡ Dual Examination Modes**:
  - **🎯 Interactive Practice Mode**: Immediate answer validation. Clicking a wrong option highlights in Red with shake feedback, instantly reveals the correct option in Green, and expands the exact reference explanation from the study material.
  - **⏱️ Timed Exam Mode**: Full 120-minute countdown simulation with OMR-style palette, answer persistence, and post-submission scorecard analytics.

- **📱 Mobile App-Like UX**:
  - Mobile bottom navigation bar for quick access.
  - Slide-up bottom sheet drawer for the 1-115 question palette.
  - Touch swipe gestures (swipe left/right between questions).
  - Tactile Web Audio synthesizer chime and buzz sound effects (with mute toggle).
  - Victory Confetti particle animation on exam submission.

- **🔤 Capital Option Letters (A, B, C, D)**: Standardized, sleek circular badges for high contrast and modern readability.
- **🎨 Premium Theme & Typography**: Fluid Dark/Light theme toggle, font scale adjuster, and responsive design powered by Google Fonts (`Mukta Malar` and `Outfit`).
- **💾 Offline Ready**: Zero external runtime dependencies; runs directly in any modern browser.

## 🚀 Quick Start

1. Clone or download this repository:
   ```bash
   git clone https://github.com/SanthaKumar-K-2004/alpha-x-solution-quiz.git
   cd alpha-x-solution-quiz
   ```
2. Open `index.html` directly in your browser or serve locally:
   ```bash
   python3 -m http.server 8080
   ```
3. Visit `http://localhost:8080` in your web browser or mobile phone.
